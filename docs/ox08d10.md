# Direct CSI0 OX08D10

The project kernel main branch is pinned to `1641cfeeb466d7a0362a474c0f7ead1953f95edb`.
The driver uses the TI four-lane HDR4 PWL12 table, 25 MHz XVCLK, and nominal
30 fps. The original TI license for the register data is retained.

The kernel recipe enables CONFIG_VIDEO_OX08D10=m and builds
`ti/k3-am67a-beagley-ai-ox08d10.dtbo`; the image installs
`kernel-module-ox08d10`. Source is already in the pinned kernel commit,
so no additional driver patch is applied.

Update or remove old BEAGLEY_KERNEL_SRCREV overrides in local.conf.
When cloning the kernel separately, check out main (the compact release
history). The local source provider defaults to sources/linux-beagley.

For this direct module, replace the old CSI0 OX03H10/SerDes overlay in the
boot partition's uEnv.txt with `ti/k3-am67a-beagley-ai-ox08d10.dtbo`.
Keep the AI and display overlays. Never enable both camera overlays on CSI0.
The module must provide the oscillator specified by the selected profile;
the connector does not generate XVCLK. GPIO16 is enable, GPIO15 is reset.

Validated on BeagleY-AI / Linux 6.12.57-ti: ID 0x580844, successful automatic
binding after reboot, V4L2 and yavta RAW capture at ~30 fps, and repeated
capture after runtime suspend. Captured buffers are 3840x2168 with 2 leading
and 6 trailing metadata rows, 16-bit little-endian storage of 12-bit samples,
7680-byte stride and 16650240 bytes per frame. Active image is 3840x2160.

This is a fixed-mode RAW driver. Exposure/gain controls, other modes, HDR
decompanding and ISP tuning are not implemented. Full image rebuild and
full dt-schema validation have not been run for this change.
